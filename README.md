# Root Pilates Company

Website for Root Pilates Company (formerly the Pilates Barre), reformer Pilates in Ridgefield, CT.

## What's here

```
index.html        The whole site: one page, with hash routes for each section
                  (#/reformer, #/back-care, #/privates, #/fusion, #/memberships, #/about)
favicon.svg       Leaf "O" from the ROOT wordmark
assets/img/       Photography, with large and small versions for responsive loading
```

There's no build step and there are no dependencies. Open `index.html` in a browser, or serve the folder with any static host.

## Publishing on GitHub Pages

Go to Settings → Pages → Build and deployment, set the source to "Deploy from a branch", and choose `main` / `(root)`. All paths are relative, so the site works at `https://kija-creative.github.io/RootPilatesCo/` or on a custom domain.

## Before launch

The brand sans is Brandon Grotesque from Adobe Fonts, and Jost stands in until it's added. Add the Adobe Fonts web project's `<link>` where the comment near the top of `index.html` marks the spot.
